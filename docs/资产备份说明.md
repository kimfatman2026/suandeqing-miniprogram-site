# 图片资产备份说明

本说明与 GitHub 仓库根目录的 `assets/` 文件夹配套使用。该目录保存当前宣传网站实际使用的图片源文件，方便迁移、审阅和后续替换；线上页面仍使用平台托管的 `/manus-storage/...` 静态地址，不直接从 GitHub 加载图片。

| 目录 | 内容 | 关联页面 |
| --- | --- | --- |
| `assets/brand/` | 算小胖首屏插画与品牌视觉图 | 首页首屏与品牌介绍。 |
| `assets/product/` | 经营总览、库存提醒、趋势、多门店、提醒等产品界面图 | 首页产品能力区。 |
| `assets/scenes/` | 零售、餐饮、服务业人物场景照片 | `/scenes` 使用场景页面。 |
| `assets/qr/` | 正式小程序二维码预留位置 | 首页与场景页扫码入口。 |

新增或替换资产时，请更新 `assets/ASSET_MANIFEST.md` 中的文件名、用途、来源/授权状态及线上静态地址。对于人物照片，务必确认拥有适合官网传播的使用授权；对于二维码，务必完成真机扫码验证后再发布。
